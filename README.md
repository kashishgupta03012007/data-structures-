# 💻 CODE 2 SUCCESS — Data Structures

**A place where practical skills meet success and innovation.**

A topic-wise collection of Data Structures and Algorithms (DSA) programming questions designed to help students practice coding, strengthen problem-solving skills, and build a strong foundation in programming.

## 📚 Topics Covered

### 1. Single-Dimensional Arrays
- Array input and traversal
- Reverse and copy arrays
- Even and positive numbers
- Maximum and minimum elements
- K-th smallest element
- Duplicate detection and removal
- Palindrome numbers
- Merging sorted arrays

### 2. Multi-Dimensional Arrays
- Matrix input and display
- Matrix addition and subtraction
- Matrix multiplication
- Matrix copying
- Scalar multiplication

### 3. Stacks
- Stack implementation using arrays
- Dynamic stack implementation
- Push, Pop, Peek, IsEmpty, and IsFull
- Reverse a string using a stack
- Bracket matching
- Sorting a stack
- Implement two stacks in a single array

### 4. Queues
- Simple queue implementation
- Circular queue
- Priority queue
- Static and dynamic implementations
- Queue insertion and deletion
- Reverse a queue
- Reverse the first K elements
- Next Greater and Next Smaller Element

### 5. Recursion
- Factorial and Fibonacci series
- Sum of natural numbers
- Decimal-to-binary conversion
- Maximum and minimum array elements
- Sum of digits
- Arithmetic mean of an array

### 6. Strings
- Uppercase, lowercase, and case conversion
- String length and comparison
- String concatenation and copying
- String reversal and palindrome checking
- Character searching
- Counting vowels, words, spaces, and lines
- String sorting and permutations
- Word replacement and occurrence counting
- ASCII value conversion

### 7. Sorting Algorithms
- Bubble Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Iterative and recursive implementations
- Sorting integer and string arrays

### 8. Searching Algorithms
- Linear Search
- Binary Search
- Iterative and recursive implementations
- Searching in integer arrays and strings

### 9. Linked Lists
- Singly Linked List
- Singly Circular Linked List
- Insertion and deletion operations
- Searching and displaying nodes
- Dynamic memory allocation

### 10. Graphs
- Graph representation using an adjacency matrix
- Depth-First Search (DFS)
- Breadth-First Search (BFS)

### 11. Trees
- Left and right views of binary trees
- Maximum depth of a binary tree
- Binary Search Tree (BST) implementation
- Insertion, deletion, and searching
- Preorder, Inorder, and Postorder traversal
- Minimum element in a BST
- Inorder predecessor and successor
- K-th smallest and largest elements
- Counting nodes in a BST
- Strictly binary, almost complete, and complete binary trees

## 🚀 Getting Started

1. Clone or download this repository.
2. Keep the HTML file and `style.css` in the same folder.
3. Open the HTML file in your browser.
4. Select a topic and click on any question to access its learning resource.
